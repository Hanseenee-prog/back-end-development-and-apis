# Prime Number Checker
This package checks if a number is a prime number and returns a boolean.

# Installation
npm install prime_number_checker

# Usage
```javascript
const checkPrime = require("./index");
console.log(checkPrime.isPrime(4)) // false;
console.log(checkPrime.isPrime(6)) // false;
console.log(checkPrime.isPrime(13)) // true;
```
